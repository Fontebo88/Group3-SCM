Group 3 — Software Configuration Management (SCM)

Project Overview

This repository contains the work for Group 3's Software Configuration Management practical. The project focuses on assessing a software development repository using Git and GitHub to evaluate collaboration practices, version control, software testing, release management, and repository maintenance.

Objectives

Assess branch management and commit message conventions.

Examine pull requests, code reviews, and collaboration practices.

Inspect tags, releases, and release documentation.

Evaluate test files and continuous integration (CI) workflows.

Identify the repository's software license and its implications.

Document gaps, risks, and recommended improvements.

Develop a prioritized improvement plan based on the assessment findings.
